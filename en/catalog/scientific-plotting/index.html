Scientific Plotting

Map experimental data to a chart and keep the plotting settings so you can rerun it and compare the results.

Science / Plotting

What it does

  • Check the plotting environment
  • Map data columns to a chart
  • Generate a figure
  • Rerun with the saved settings and compare results

When to use it

  • Create a reproducible figure for a paper
  • Compare the inputs and outputs of two runs

Current status

The SciForge Acceptance test build verified environment checks, data mapping, rendering, reruns and comparison, as well as version history and the plugin lifecycle.
